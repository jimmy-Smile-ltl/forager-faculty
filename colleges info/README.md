# Step 1 · 学校信息采集 —— 全国高校主名单（三源融合）

> 阶段定位：**四阶段流水线的第一站**。产出全国高校主名单（学校名称 + 官网入口 +
> 985/211/双一流标签 + 排名等公开属性），是后续所有阶段的选校依据。

```
   Step 1 ★(当前)        Step 2                Step 3             Step 4
   学校信息采集    →      二级院系采集    →     教师名录采集   →   教师详情采集
   colleges info/        colleges department/  department teachers/  teachers/
   (全国主名单)          (选校→院系+URL)       (姓名+详情URL)       (13字段)
```

## 输入与产出

| | 说明 |
|---|---|
| **输入** | 三个公开数据源（见下表），无需配置即可重采 |
| **产出** | `unified_colleges.csv` —— 以教育部名单为主键的合并大表（2,952 校 × 34 列） |
| **下游消费者** | Step 2 按 `is_985`/`is_211`/`is_first_flow` 筛出 144 所目标校 |

本阶段为**纯数据源采集**：目标站点是教育部/掌上高考/学信网的公开 API 与页面，
结构稳定、无反爬博弈（学信网需 Playwright 过瑞数），不涉及评估-修复循环。

## 三源数据概览

| 数据源 | 网址 | 条数 | 核心字段 | 采集方式 |
|--------|------|------|----------|----------|
| **教育部** | hudong.moe.gov.cn | 2,952 | 学校名称、标识码、主管部门、所在地、办学层次 | HTTP API (curl_cffi) |
| **掌上高考** | gaokao.cn | 2,991 → 匹配 2,897 | 校徽、院校特色(985/211/双一流…)、保研星级、软科/校友会/QS/US News排名、学科评估 | HTTP API + 详情 JSON (curl_cffi) |
| **学信网** | chsi.com.cn | 2,921 → 匹配 2,809 | 学校网址、招生网址、电话、微信/微博/百家号 | Playwright 浏览器自动化 (绕过瑞数) |

**为什么以教育部名单为主键**：它是唯一权威且完整的全国普通高校名单（含主管部门、
所在地、办学层次），另两源作为属性补充左右关联。学校**官网 URL 来自学信网**
（`学校网址` 列，覆盖 95%）——这正是 Step 2 采集院系时的入口。

## 核心机制

### 合并逻辑（`merge_unified.py`）

三源学校名对齐采用三级匹配：

1. **精确匹配**: 全角/半角括号统一后完全一致
2. **子串匹配**: 如掌上高考的 `华北电力大学（北京）` 匹配到教育部的 `华北电力大学`
3. **模糊匹配**: score ≥ 0.85 的相似名称 (如 `河北石油职业技术学院` → `河北石油职业技术大学`)

> 55 所已停办/更名的院校 (如独立学院、合并院校) 未匹配到掌上高考数据。

### 分校区识别 ⚠️

教育部名单以**独立法人**为单位，分校区不单独列出。但分校区的官网往往是独立的，
直接进入 Step 2 会漏采——需要按下表规则识别：

| 情况 | 判断标准 | 典型示例 |
|------|----------|----------|
| 独立域名 | 完全不同的二级域名 | 哈工大 `hit.edu.cn` → 威海 `hitwh.edu.cn` |
| 子域名 | 主校域名的三级子域 | 合工大 `hfut.edu.cn` → 宣城 `xc.hfut.edu.cn` |
| 同一域名 | 域名完全相同 | 北师大 `bnu.edu.cn` → 珠海 `bnu.edu.cn` |

## 运行方式

在**仓库根目录**执行（`uv` 自动管理环境）：

```bash
# 重新采集（各源支持独立运行与断点续爬）
cd "colleges info/moe_gov"    && uv run python scrape_colleges.py   # 教育部名单
cd "colleges info/gaokao_cn"  && uv run python scrape_gaokao.py     # 掌上高考
cd "colleges info/chsi"       && uv run python scrape_chsi.py       # 学信网 (需 Playwright)

# 重新合并三源
cd "colleges info" && uv run python merge_unified.py
```

## 环境依赖

- Python 3.14+（uv 管理，仓库根 `uv sync`）
- `curl_cffi`: 模拟浏览器指纹绕过 WAF（教育部 / 掌上高考）
- `playwright`: 学信网瑞数反爬绕过
- `beautifulsoup4` / `lxml`: HTML 解析
