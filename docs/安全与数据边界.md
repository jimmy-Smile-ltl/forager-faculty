# 安全与数据边界 — 发布审计记录与数据分级

> **English summary**: This doc records the pre-release security audit and the
> data-tiering policy of the repository. The audit (run item-by-item before
> open-sourcing) found: zero key/token/password leaks anywhere (all secrets are
> injected via `.env` / `tokens.json`, both gitignored); zero intranet
> addresses (gateway URLs come only from the `LLM_BASE_URL` env var); all
> teacher personal info in test fixtures / knowledge bases is pseudonymized;
> zero hardcoded machine paths; and all keys in logs are masked. Distribution
> stops at the department-URL-list level: school info and the QS overseas list
> are distributed, teacher rosters and teacher details are not — their
> framework is preserved but their data products are generated at runtime and
> gitignored, so there is no accidental-commit path.

## 发布前安全审计（开源前逐项执行）

| 检查项 | 结果 |
|---|---|
| 密钥泄漏（`sk-`、API key、token、password 全仓扫描） | ✅ 零命中；无任何真实密钥，全部由 `.env` / `tokens.json`（均 gitignore）注入 |
| 内网地址（企业内部域名 / 内网 IP 段） | ✅ 零命中；网关地址仅通过 `LLM_BASE_URL` 环境变量配置，代码无默认值 |
| 教师个人信息（测试夹具、知识库、示例数据） | ✅ 全部化名/占位处理（`某教师`、`example.edu.cn`、真实电话清零） |
| 本机绝对路径硬编码 | ✅ 零命中；全部 `Path(__file__)` 推导 |
| 日志与控制台输出 | ✅ 密钥一律脱敏（前 8 位 + `...` + 后 4 位，`mask_sk`） |

审计后仓库新增内容的增量检查项：

| 检查项 | 结果 |
|---|---|

## 数据分级

仓库分发物止步于「院系 URL 清单」层级；教师级数据（名录/详情）只能由
使用者自行运行框架采集，且框架产物目录全部 gitignore，不存在误提交路径。

| 层级 | 是否随仓库分发 |
|---|---|
| 学校信息（名称/主管部门/985/211/排名等公开属性） | ✅ `colleges info/unified_colleges.csv` |
| 海外高校名单（QS 2027：校名/排名/官网 URL） | ✅ `colleges info/qs_oversea/qs_rankings_2027_with_website.csv`（1,504 所，官网 100% verified） |
| 院系清单（学校 → 院系名称 + 院系官网 URL） | ✅ `colleges department/depart_985211.csv` + `depart_985211.jsonl` |
| 教师名录（姓名 + 详情页 URL） | ❌ 不分发；运行 `department teachers/` 框架自行采集 |
| 教师详情（13 字段 + 原始页面） | ❌ 不分发；运行 `teachers/` 框架自行采集 |

所有运行时输出目录（`colleges department/output/`、`department teachers/output/`、
`teachers/<学校>/`）均在 `.gitignore` 中排除——**spider 脚本、评估报告、采集数据
一律在运行时生成，不随仓库分发**；仓库只包含经过验证的采集框架本身。

## 合规工作流（提交/推送前必跑）

按本仓库的合规要求，每次 commit / push 前执行：

1. **全局扫描**：`grep -rE '(secret|password|token|apikey|api_key|access_key|secret_key|appsecret|signkey|private_key|authorization.*Bearer)' --include='*.{py,json,md,yaml,yml,toml,sh}' .`
2. **内网地址**：`grep -rE '(10\.[0-9]+\.|172\.(1[6-9]|2[0-9]|3[0-1])\.[0-9]+\.|192\.168\.[0-9]+\.)' .`（127.0.0.1 本地端口除外）
3. **大文件**：`find . -type f -size +1M`（超过 1MB 需确认内容后再提交）
4. 发现敏感信息：立即停止 push；已 push 则联系安全团队，不要 force push 覆盖。
